本软件是基于视频图像识别的数字时钟自动校准工具。通过分析包含被校时钟和标准时钟的视频画面，自动检测时钟末位数字跳变帧，利用OCR技术识别两个时钟的显示时间，计算时间偏差并生成校准记录。适用于时间频率计量检定领域，可替代人工目视读数和手工计算的传统校准方式，显著提高校准效率和准确性。

## 三、软件说明书

### 第一部分：软件概述

#### 1.1 软件名称
数字时钟自动校准系统（Digital Clock Automatic Calibration System，简称 DC_Calibration）V2.0

#### 1.2 开发背景

在时间频率计量检定工作中，数字时钟的校准通常依赖人工操作：检定员同时观察被校时钟和标准时钟的显示，在时钟末位进位瞬间手动记录两个时钟的示值，再计算时间偏差。这种方式存在以下问题：

1. **人工反应速度有限**：人的视觉反应时间约为 150-300ms，难以捕捉高速跳变的准确时刻；
2. **读数一致性差**：不同检定员的读数习惯和反应速度不同，引入主观偏差；
3. **工作效率低**：每次校准需要反复观察、记录、计算，耗时较长；
4. **无法处理高频显示**：对于显示刷新率较高（如毫秒级）的数字时钟，人工已无法有效读数。

为解决上述问题，开发了本软件。它利用计算机视觉技术，通过分析录制好的视频（包含被校时钟和标准时钟同框画面），自动完成跳变帧检测、时间OCR识别和偏差计算，将传统手工操作转变为自动化流程。

#### 1.3 适用范围

本软件适用于各类数字显示时钟的计量校准，包括但不限于：

- 七段数码管显示的电子时钟
- LED/LCD数字时钟
- 具有毫秒显示的高精度数字时钟
- 数字式秒表、计时器
- 其他数字显示的时间计量器具

适用场景：各级计量技术机构、校准实验室、科研院所的时频计量检定工作。

### 第二部分：软件功能描述

#### 2.1 功能总览

本软件采用四步向导式操作流程，引导用户完成一次完整的数字时钟校准：

**步骤一：加载视频**

- 支持拖拽或点击选择视频文件
- 支持 MP4、AVI、MOV、MKV、WMV、FLV、WebM 等主流视频格式
- 自动识别视频分辨率、帧率、帧数、时长等元数据
- 提供历史校准记录快捷入口

**步骤二：框选时钟区域**

- 自动检测画面中的数字时钟显示区域（基于颜色掩码和数字轮廓分析）
- 提供红色矩形框用于框选"被校时钟"区域
- 提供绿色矩形框用于框选"标准时钟"区域
- 支持矩形四角拖拽调整大小、方向键微调位置（每次1px）
- 实时显示框选区域的坐标和尺寸

**步骤三：检测跳变并确认清晰帧**

- 自动分析视频中被校时钟末位数字的跳变（进位）帧
- 支持彩色LED时钟的颜色像素计数法和亮度比法两种检测模式
- 在跳变帧前后各2帧（共5帧）范围内进行清晰度评估
- 三指标综合评分：Laplacian方差（锐度）+ 过渡态检测（数字稳定度）+ SSIM一致性（结构相似度）
- 推荐最佳识别帧，用户可逐帧浏览确认
- 支持"找下一个跳变"和"重新寻找"功能

**步骤四：查看结果并保存**

- 后台异步OCR识别被校时钟和标准时钟的显示时间（不阻塞界面）
- OCR引擎自动进行互相纠错（用标准钟小时修正被校钟的OCR误读）
- 自动计算时间偏差（被校时间 - 标准时间）
- 支持手动修正OCR识别结果
- 填写设备信息（名称、型号、编号、生产厂家、送检单位）
- 一键保存校准记录到SQLite数据库
- 支持开始新校准的流程重置

#### 2.2 辅助功能

- **历史记录管理**：查看、搜索（全字段模糊匹配）、删除历史校准记录，支持导出CSV文件
- **自学习模板**：OCR引擎在用户确认结果后自动学习当前字体模板，持续提高识别准确率
- **自动ROI检测**：首次进入时钟框选页面时自动预选时钟区域，减少手工操作

#### 2.3 核心算法流程

```
视频加载 → 自动ROI检测 → 用户确认/调整ROI
    ↓
跳变帧检测（帧差+颜色分析）→ 找到末位进位帧
    ↓
清晰度评估（5帧窗口，三指标综合评分）→ 推荐最佳识别帧
    ↓
OCR识别（EasyOCR + 七段规则法 + 模板匹配三级回退）
    ↓
时间解析 + 偏差计算 → 保存校准记录
```

### 第三部分：技术特点

#### 3.1 创新点

**（1）颜色掩码LED数码管跳变帧检测**

传统帧差法对暗光环境或低对比度视频效果不佳。本软件首创颜色掩码检测模式：对绿色LED时钟，提取绿色通道像素，统计亮像素数量变化率，通过局部峰值检测定位进位瞬间；对红色LED时钟，采用精确末位数字区域提取+亮度比法。该双模策略显著提高了低光环境下的检测成功率。

**（2）自动ROI检测**

基于颜色空间分析（红/绿LED掩码提取）结合数字轮廓行分组算法，首次进入框选页面时自动识别画面中的数字时钟区域并预选框选。支持红色LED（被校时钟常见）和绿色LED（标准时钟常见）的自动区分，按从上到下排列分别框选。

**（3）完全离线OCR**

基于EasyOCR引擎实现完全本地化OCR识别，不需要网络连接。配合七段数码管规则识别法和自学习模板匹配构成三级回退机制：EasyOCR主力识别 -> 七段区域亮度法回退 -> 像素密度模板匹配兜底。支持领域专用字符映射纠正OCR常见错误（如"/"强制修正为"1"，"2801"自动修正为"2001"等）。

**（4）自适应阈值算法**

跳变检测的阈值不由用户手工设定，而是根据视频内容自动计算：统计所有帧差分数，取P95和P99百分位数，根据两者的比值（反映信号峰的尖锐程度）自动选择最优阈值系数。同时结合视频整体亮度稳定性（全局CV值）动态微调，有效应对不同光照条件和时钟类型。

#### 3.2 技术架构

本软件采用**三层架构 + Qt信号驱动**设计：

```
GUI层 (main.py + gui/*.py)
  ↕ pyqtSignal / QThread（信号槽+后台线程）
核心服务层 (core/*.py)
  ↕ 函数调用
数据层 (data/*.py)
```

- **GUI层**：基于 PySide6（Qt for Python），实现视频播放、ROI框选、清晰帧浏览、OCR结果展示等交互界面
- **核心服务层**：纯Python实现，不依赖Qt，包含跳变检测、清晰度评估、OCR识别、视频IO等核心算法，可独立测试
- **数据层**：SQLite数据库 + Repository模式，封装校准记录的CRUD、搜索、CSV导出等数据操作

#### 3.3 关键技术实现

| 技术点 | 实现方案 |
|--------|----------|
| 视频读取 | OpenCV VideoCapture + LRU帧缓存（O(1)命中） |
| 跳变检测 | 帧间颜色像素变化率 + 局部峰值检测 + 早停模式 |
| 清晰度评估 | Laplacian方差(50%) + 过渡态双峰检测(35%) + SSIM一致性(15%) |
| OCR识别 | EasyOCR为主 + 七段区域亮度法回退 + 自学习模板匹配 |
| 时间解析 | 正则多模式匹配 + 字段标记（区分原文真实存在的分量） |
| 偏差计算 | 自动分量对齐（仅比较两者共有的日期/时间字段） |
| 数据库 | SQLite + WAL模式 + 自动迁移 + 备份恢复 |

## 五、附加说明

### 5.1 与其他软件的区分

本软件与市场上通用视频分析软件、通用OCR软件的区别在于：

1. **领域专用性**：专门针对数字时钟校准场景，内置跳变帧检测、时间格式解析、偏差自动计算等计量领域专属功能；
2. **离线运行**：所有算法均在本地运行，不依赖云端服务，满足计量检定环境的网络安全要求；
3. **完整的检定流程**：从视频加载到记录保存的完整闭环，而非通用的视频分析或OCR工具；
4. **多级回退机制**：OCR引擎设计了三层回退策略，确保在不同字体、光照条件下均有可用输出。
