#### 专利1：CN103065152B —— 一种视频中数字时钟的识别方法（最相关）

| 项目 | 内容 |
|------|------|
| **专利权人** | 华中师范大学 |
| **发明人** | 余新国 |
| **申请日** | 2012年12月10日 |
| **授权日** | 2015年11月18日 |
| **法律状态** | 已授权，有效 |
| **IPC分类** | G06K 9/62; G06K 9/00 |

**核心技术方案**：
- 利用秒位数字周期性变化规律（每R帧变化一次），通过像素灰度值在前后R帧内的稳定性变化搜索"潜在转换像素点"
- 定义评估函数S(i)在10×R帧范围内搜索秒位转换帧（峰值处）
- 利用Q(p)函数统计像素在多个秒周期内的变化一致性，聚类确定秒位数字粗选区域
- 通过高斯混合模型（GMM）确定数字颜色和背景颜色，Hough-like方法建模四个数字区域位置关系
- 数字序列模板匹配（0~9的11帧序列模板内积匹配）
- 实时训练分类器（Bayes/BP/SVM）识别分钟

**与本发明的主要区别**：

| 维度 | CN103065152B | 本发明（DC_Calibration） |
|------|-------------|------------------------|
| 跳变检测方式 | 灰度像素周期性变化一致性 | **颜色掩码法（绿LED）+ 亮度比法（红LED）** 双模分流 |
| 颜色信息利用 | GMM统计颜色，仅用于区域精确定位 | **颜色通道比值**直接用于跳变检测，主动检测LED颜色选择策略 |

| 假阳性过滤 | 无专门机制 | **跳前跳后双CV稳定性验证** |
| 末位定位 | 像素变化一致性聚类 | **自适应二值化+轮廓检测+行间隙分离** |
| OCR | 数字序列模板 + 实时训练分类器 | **EasyOCR+七段规则法+自学习模板** 三层回退 + **互相纠错** |

## 2. 新颖性与创造性论证

### 2.1 新颖性分析（Novelty）

根据《专利法》第二十二条第二款，新颖性要求"不属于现有技术"。逐一分析如下：

#### 创新点A：颜色掩码跳变检测法 + LED颜色分流策略

**现有技术**：CN103065152B 使用灰度像素在前后R帧内的稳定性变化来检测跳变帧，属于灰度域的周期性分析，不使用颜色通道信息进行跳变检测。

**本发明的区别**：
- 采用颜色通道比值（G > R×1.5, G > B×1.5）构建颜色掩码，利用LED发光的光谱特性直接提取显示段像素
- 自动检测LED颜色，按颜色分流到不同检测策略：绿LED用颜色像素计数变化率法，红LED用亮度比法
- 颜色像素计数变化率 = |cnt[i] - cnt[i-1]| / cnt[i-1]，聚焦于LED段亮灭导致的颜色像素数突变

**结论**：颜色掩码跳变检测法 + LED颜色分流策略在现有专利中未见公开，**具备新颖性**。

#### 创新点B：跳前跳后双稳定性验证

**现有技术**：CN103065152B 无专门的假阳性过滤机制；通用帧差法仅用固定阈值过滤。

**本发明的区别**：
- 利用真跳变的核心物理特征：跳变后数字进入稳定显示状态，亮度变异系数（CV）明显下降
- 三条件联合判定：post_cv < global_cv（比全局更稳定）、post_cv < pre_cv × 0.5（比跳前显著稳定）、亮度变化 > 0.3%
- 有效区分真跳变和相机自动曝光引起的亮度突变

**结论**：跳前跳后CV稳定性验证法在现有专利中未见公开，**具备新颖性**。

#### 创新点C：双时钟OCR互相纠错（完全离线）

**现有技术**：CN116170104A 和 US 10,957,360 均依赖网络/NTP获取参考时间，非完全离线。CN103065152B 仅识别单一时钟。

**本发明的区别**：
- 完全离线，利用同框拍摄的两个时钟之间的时间关系（小时值相同或差±1）进行互相纠错
- 领域专用OCR混淆字符映射表（'/'→'1', '2826'→'2026', '80'→'00'等）
- 无需任何外部网络/服务器，适用于计量检定现场

**结论**：完全离线的双时钟OCR互相纠错在现有专利中未见公开，**具备新颖性**。

#### 创新点D：全自适应百分位阈值体系（用于时钟校准）

**现有技术**：CN101582160A 在通用前景检测中使用百分比曲线+斜率跳变选阈值，但未应用于数字时钟校准领域。

**本发明的区别**：
- 将百分位自适应阈值**专门设计**用于时钟跳变帧检测场景
- 多层阈值体系：P50+(P95-P50)×multiplier（颜色法）、P99×0.6或P95×0.9自动选择（亮度比法）
- 全局CV动态修正（CV<0.005→阈值×1.5, CV<0.01→阈值×1.2）
- 降阈值回退机制（降低50%继续搜索）

**结论**：全自适应百分位阈值体系虽基于已知的统计方法，但其**在数字时钟跳变帧检测这一特定领域的应用**以及与颜色掩码法/亮度比法的深度耦合设计，在现有专利中未见公开，**具备新颖性**。

#### 创新点E：精确末位数字定位（自适应二值化+轮廓+行间隙）

**现有技术**：CN103065152B 通过像素变化一致性聚类定位数字区域。

**本发明的区别**：
- P98百分位自适应二值化（亮画面用OTSU，暗画面用P98×0.5）
- 轮廓检测+尺寸过滤筛选数字块
- 行间隙检测（gap>10px）分离日期行和时间行
- 从右下角精确取最后一个数字块

**结论**：精确末位数字定位的完整流程在现有专利中未见相同公开，**具备新颖性**。

### 2.2 创造性分析（Inventive Step）

根据《专利法》第二十二条第三款，创造性要求"突出的实质性特点和显著的进步"。

#### 创造性论证要点

1. **技术启示（Teaching Away）**：
   - 传统方法（如CN103065152B）采用灰度分析方法，本领域技术人员没有动机将颜色通道比值分析引入跳变检测，因为传统认识中"跳变检测=帧差/灰度变化"，颜色信息被认为仅用于定位而非检测
   - LED发光的光谱特性（G通道显著强于R/B通道）作为检测信号的利用，不是常规技术手段

2. **非显而易见性（Non-Obviousness）**：
   - 红/绿LED分流策略不是简单的"两种方法排列组合"，而是针对两种LED的光谱特性和相机传感器的不同响应设计的两套独立检测逻辑
   - 跳前跳后CV验证利用的是"跳变后数字进入稳定显示状态"这一物理特征，不是简单的阈值过滤
   - 多个创新点的有机结合（颜色掩码+CV验证+自适应阈值+回退机制）产生了1+1>2的技术效果

3. **技术效果（Technical Effect）**：
   - 8个测试视频全部在±2帧偏差内检测成功（100%成功率）
   - 覆盖极暗（mean=2.6）到正常（mean=22）的光照范围
   - 零人工调参，一键自动检测
   - 完全离线运行

4. **解决长期未解决的技术问题**：
   - 高帧率视频中相机自动曝光导致的假阳性——通过CV稳定性验证有效解决
   - 不同光照条件下单一阈值失效——通过全自适应百分位体系解决
   - 不同LED颜色的数码管需不同方法——通过颜色分流策略解决

### 2.3 综合评估

| 创新点 | 新颖性 | 创造性 | 总体评价 |

## 4. 技术交底书 —— 核心专利

### 4.1 专利1技术交底书

---

#### 一、发明名称

基于颜色掩码与双模分流的数字时钟跳变帧检测方法及系统

#### 二、技术领域

本发明属于时间频率计量技术领域，具体涉及一种基于视频图像分析的LED数字时钟进位跳变帧自动检测方法及系统，适用于遵循JJF 2199-2025《数字式时钟校准规范》的数字时钟校准场景。

#### 三、背景技术

在时间频率计量领域，数字式时钟（包括LED数码管时钟、LCD时钟等）广泛应用于实验室、通信基站、电力系统等场景。根据国家计量技术规范JJF 2199-2025的要求，数字时钟的校准需要将标准时钟（参考时间源）与被校时钟同框拍摄视频，分析视频中时钟末位数字跳变（进位）的瞬间帧，读取时间值并计算偏差。

现有技术中，跳变帧的检测主要采用以下几种方法：

（1）**人工逐帧回放**：计量检定人员逐帧回放视频，肉眼寻找进位瞬间。该方法效率极低，主观性强，且对于2100+fps的高速摄影视频无法有效处理。

（2）**灰度帧间差分法**：计算相邻帧的整体灰度差异，差异最大处判定为跳变帧。但该方法对光照变化、相机自动曝光等干扰极其敏感，容易产生假阳性。

（3）**像素变化周期分析法**（如CN103065152B）：利用像素灰度值在秒位变化周期内的稳定性变化特征搜索跳变帧。但该方法仅使用灰度信息，未利用LED发光的光谱特性，对暗光场景和不同LED颜色缺乏适应性。

（4）**时间戳/网络基准法**（如CN122159991A、CN116170104A）：需要通过网络获取标准时间进行比对。但对于计量检定现场，通常无网络环境，这些方法不可用。

综上所述，现有技术存在以下不足：
- 未利用LED发光颜色信息进行跳变检测
- 未对不同颜色的LED采取差异化检测策略
- 未建立有效的假阳性过滤机制（特别是相机自动曝光干扰）
- 检测阈值需人工调整，无法适应不同光照条件
- 完全离线运行的需求未被满足

#### 四、发明内容

##### 4.1 发明目的

本发明的目的在于提供一种基于颜色掩码与双模分流的数字时钟跳变帧检测方法及系统，以解决现有技术中跳变帧检测精度低、抗干扰能力弱、需要人工调参、无法完全离线运行的问题。

##### 4.2 技术方案

本发明提供一种基于颜色掩码与双模分流的数字时钟跳变帧检测方法，包括以下步骤：

**步骤S1：加载视频，检测时钟LED颜色类型**

取视频第一帧中时钟ROI区域，分析RGB三通道的颜色特征。若ROI区域内满足 G > R×α₁ 且 G > B×α₁ 且 G > β₁ 的像素占比超过预设阈值（如α₁=1.5, β₁=25），判定为绿色LED；否则判定为红色LED。

**步骤S2：根据LED颜色类型，分流至对应的检测策略**

- 若为绿色LED，执行步骤S3（颜色像素计数变化率法）
- 若为红色LED，执行步骤S4~S5（精确末位数字定位 + 亮度比法）

**步骤S3：颜色像素计数变化率法（绿色LED路径）**

S3.1：取ROI右侧预设比例区域（如右侧30%），该区域对应时钟末位数字（秒个位）的显示位置。

S3.2：逐帧计算绿色像素数量：对每一帧，统计满足 G > R×α₁ 且 G > B×α₁ 且 G > β₁ 的像素个数，记为绿色像素数 cnt[i]。

S3.3：计算相邻帧绿色像素数的变化率：diff[i] = |cnt[i] - cnt[i-1]| / cnt[i-1]。

S3.4：在diff序列中检测局部峰值信号：ratios[i] = diff[i] / median(diff[i-k], diff[i-k+1], ..., diff[i+k])，其中k为窗口半径。

S3.5：自适应阈值计算：基于diff序列的统计分布，取P50和P95百分位值，计算阈值 th = P50 + (P95 - P50) × m，其中m为倍数因子（标准模式m=2.5，降低阈值模式m=1.5）。

S3.6：跳变候选帧判定：ratios[i] ≥ th 且 ratios[i] ≥ median(neighbors) × 2，满足条件的帧i为跳变候选帧。然后执行步骤S6。

**步骤S4：精确末位数字定位（红色LED路径的预处理）**

S4.1：对时钟ROI区域进行灰度化，计算P98百分位亮度值。

S4.2：自适应二值化：若ROI平均亮度较高（如mean≥30），采用OTSU法；若较暗，采用P98×0.5作为二值化阈值。

S4.3：对二值化图像进行轮廓检测，过滤条件：宽度≥4像素且高度≥10像素，筛选出数字字符块。

S4.4：按纵坐标排序，检测行间隙（行间gap>10px），分离日期行和时间行。

S4.5：取时间行的数字字符块，按横坐标排序，取最右侧一个字符块作为精确末位数字ROI，加预设边距（如2px）扩展。

**步骤S5：亮度比法（红色LED路径）**

S5.1：在步骤S4得到的精确末位数字ROI上，逐帧计算平均灰度亮度：bright[i] = mean(gray(ROI))。

S5.2：计算滑动窗亮度均值变化率：scores[i] = |mean(bright[i+1, i+w]) - mean(bright[i-w, i-1])| / max(mean_before, mean_after)，其中w为窗口大小（如w=3）。

S5.3：自适应阈值计算：
- 计算 scores 序列的 P95 和 P99 百分位值
- 计算 gap = P99 / P95
- 若 gap > 3，则 threshold = P99 × 0.6
- 否则 threshold = P95 × 0.9
- 计算全局CV（变异系数），CV < 0.005 时 threshold ×= 1.5，CV < 0.01 时 threshold ×= 1.2

S5.4：峰值检测：scores[i] ≥ threshold 且 scores[i] ≥ median(neighbors) × 检测灵敏度因子。

**步骤S6：跳前跳后稳定性验证（假阳性过滤）**

S6.1：对每个跳变候选帧i，分别取跳变前15帧和跳变后15帧的亮度序列。

S6.2：计算跳变前帧的亮度变异系数 pre_cv 和跳变后帧的亮度变异系数 post_cv。

S6.3：全局变异系数 global_cv 取全序列滑动窗CV的中位数。

S6.4：同时满足以下三个条件，确认候选帧为真跳变帧：
- 条件1：post_cv < global_cv（跳变后帧比全局平均水平更稳定）
- 条件2：post_cv < pre_cv × 0.5（跳变后帧比跳变前帧显著更稳定）
- 条件3：跳变前后亮度变化幅度 > 0.3%（确认有实质性变化而非纯噪声）

**步骤S7：分层回退策略**

S7.1：步骤S6验证通过 → 返回跳变检测结果。

S7.2：步骤S6验证失败 → 降低检测阈值（如threshold ×= 0.5），放宽峰值判定条件，重新执行S3/S5检测，再次验证。

S7.3：降低阈值仍失败 → 切换至"查找下一个跳变"模式，跳过稳定性验证，提高检测灵敏度。

**步骤S8：微调和输出**

在候选跳变帧±3帧范围内，找到信号最强的帧，返回该帧号及检测结果信息。

##### 4.3 有益效果

与现有技术相比，本发明具有以下有益效果：

（1）**高检测精度**：8个测试视频全部在±2帧偏差内成功检测（100%成功率），覆盖极暗（mean=2.6）到正常照明（mean=22）的光照范围。

（2）**强抗干扰能力**：通过跳前跳后CV稳定性验证，有效过滤相机自动曝光调整引起的假阳性，尤其适用于高帧率（2100+fps）视频。

（3）**零人工调参**：全自适应百分位阈值体系，基于数据统计特征（P50/P95/P98/P99）自动计算所有阈值参数，一键即可完成检测。

（4）**多场景覆盖**：红/绿LED分流策略，针对不同颜色LED的光谱特性采用不同的检测方法，覆盖主流数字时钟的LED类型。

（5）**完全离线运行**：无需网络连接、无需服务器，所有算法均在本地执行，适用于计量检定现场。

#### 六、具体实施方式

##### 实施例1：绿色LED时钟的标准检测

场景：被校时钟为绿色LED数码管，室内正常照明（ROI平均亮度≈20），视频帧率30fps。

（1）加载视频，取第一帧ROI区域，计算 G>R×1.5 且 G>B×1.5 且 G>25 的像素占比，结果为38%，超过预设阈值，判定为绿色LED。

（2）进入绿LED路径：取ROI右侧30%区域，逐帧统计绿色像素数cnt[i]。

（3）计算变化率diff[i]，在diff序列中检测局部峰值。

（4）计算P50=0.05, P95=0.23，阈值th = 0.05 + (0.23-0.05) × 2.5 = 0.50。

（5）检测到帧号N处的ratios[N] = 3.2 > 0.50，且 > median(neighbors)×2，判定为候选。

（6）跳变前15帧CV=0.008，跳变后15帧CV=0.002，global_cv=0.004，亮度变化=2.1%。满足三个条件，确认为真跳变。

（7）±3帧微调找到信号最强帧，返回检测结果。

##### 实施例2：极暗环境 + 降低阈值回退

场景：被校时钟为红色LED，极暗环境（ROI平均亮度=2.6），视频帧率30fps。

（1）判定为红色LED → 进入红LED路径。

（2）执行精确末位数字定位：暗画面用P98×0.5 = 5×0.5 = 2.5 作二值化阈值，成功定位末位数字区域。

（3）亮度比法扫描：scores全序列P95=0.03, P99=0.08, gap=2.67→threshold=0.08×0.6=0.048。

（4）标准阈值下未检出显著峰值，触发降阈值回退：threshold=0.048×0.5=0.024。

（5）降阈值后检出候选帧，CV验证通过，返回结果。

S2、对所述初始识别文本执行领域专用字符纠错，包括将预定义映射表中的混淆字符替换为正确字符；

S3、解析标准时钟识别文本，提取其中的时间信息，分离日期部分和时间部分，获取标准时钟的小时数值；

S4、解析被校时钟识别文本，提取其首位数字字符（通常为小时位），将其与标准时钟的小时数值进行比较，当差值在预设合理范围（如1~11小时）内时，使用标准时钟的小时数值修正被校时钟对应位置的识别结果；

S5、输出修正后的被校时钟时间和标准时钟时间。

**从属权利要求2**：步骤S1中，所述OCR识别采用多层回退策略：第一层使用EasyOCR深度学习引擎；若第一层识别结果的置信度低于阈值或结果不可信，回退至第二层七段数码管规则法，通过判定七段数码管各段区域的亮灭状态识别数字；若第二层仍失败，回退至第三层自学习模板匹配法。

**从属权利要求3**：所述七段数码管规则法具体为：对数字区域进行七段区域划分，计算每个段区域的像素亮度均值，根据各段亮度值与全局阈值的比较判定该段的状态（亮/灭），将亮灭状态组合与标准七段编码表匹配获得数字。

**从属权利要求4**：所述自学习模板匹配法具体为：在用户手动修正OCR识别结果后，自动从当前帧图像中提取各数字字符的二值化区域图像，缩放到统一尺寸后存入模板库；后续识别时，使用归一化相关系数匹配法将待识别图像与模板库中所有模板逐一匹配，取匹配度最高者。

**从属权利要求5**：步骤S1中，若被校时钟显示区域高度超过预设值，判定为双行显示（同时包含日期行和时间行），执行双行识别：在显示区域中间三分之一区域检测最暗行作为分割线，分别对上区域和下区域执行OCR识别，其中包含4位连续数字的行识别为日期行，包含冒号字符的行识别为时间行。

**从属权利要求6**：步骤S2中，所述预定义映射表至少包括以下映射规则：

| 原字符 | 替换字符 | 适用场景 |
|--------|---------|---------|
| '/' | '1' | LED数码管'1'的细笔画常被OCR误识别为'/' |
| '\' | '1' | 同上 |
| '2826' | '2026' | OCR将'20'合并误识为'28' |
| '80' | '00' | '8'→'0'是LED字体常见OCR错误 |
| '87' | '07' | 月份/秒数个位常见OCR错误 |
| 'O' | '0' | 通用OCR混淆 |
| 'S' | '5' | 通用OCR混淆 |
| 'B' | '8' | 通用OCR混淆 |

**独立权利要求7 —— 系统**

一种基于互相纠错的离线双时钟OCR识别系统，其特征在于，包括OCR识别模块、领域字符纠错模块、互相纠错模块和双行识别模块。

### 6.5 风险提示

1. **CN103065152B** 是最接近的现有技术，需要在说明书和权利要求中**充分强调技术区别**，特别是：颜色掩码法（非灰度像素法）、双模分流（非单一方法）、CV稳定性验证（非简单阈值）、自适应百分位阈值体系。
2. **CN122159991A** 是2026年1月申请的新专利，需关注其审查结果。但两者的应用场景和技术方案差异显著（网络依赖 vs 离线、设备时间戳校准 vs 时钟显示时间校准）。

4. 专利2的**互相纠错**特征需要与CN116170104A充分区分，强调"完全离线"和"同框双时钟"的区别。
